# Alcance del MVP

## Incluido

### Tableros

- Crear tableros.
- Listar tableros.
- Consultar un tablero.
- Eliminar un tablero.

### Nodos

- Crear nodos de escena o teoría.
- Consultar nodos por tablero.
- Actualizar posición.
- Eliminar nodos y sus relaciones dependientes.

### Escenas

- Crear contenido de escena asociado a un nodo.
- Consultar escenas.
- Consultar una escena por identificador.
- Editar sus datos principales.

### Teorías

- Crear contenido de teoría asociado a un nodo.
- Consultar teorías.
- Consultar una teoría por identificador.
- Editar sus datos principales.

### Conexiones

- Crear relaciones entre nodos.
- Listar conexiones.
- Eliminar conexiones.
- Impedir conexiones inválidas entre tableros diferentes.

### Visualización

- Recuperar el grafo de un tablero.
- Transformar el grafo al formato de React Flow.
- Mostrar nodos sobre un canvas.
- Mover, seleccionar, acercar y desplazar la vista.

## Excluido del MVP

- Registro e inicio de sesión.
- Perfiles de usuario.
- Colaboración simultánea.
- Comunidad o publicación de tableros.
- Inteligencia artificial.
- Detección automática de spoilers.
- Líneas temporales automáticas.
- Importación automática desde plataformas audiovisuales.
- Personajes y lugares como entidades independientes.
- Aplicación móvil nativa.

## Restricciones

- En el MVP el uso es personal.
- Las imágenes se agregarán manualmente cuando esa función sea implementada.
- El frontend del Sprint 1 no consume todavía la API.
- El despliegue productivo se reserva para un sprint posterior.

## Criterio para ampliar el alcance

Una funcionalidad nueva solo debe entrar al MVP si es necesaria para validar la experiencia central de organizar escenas y teorías mediante conexiones visuales.
