# Visión y objetivos

## Visión del producto

Permitir a los usuarios capturar escenas relevantes de obras audiovisuales y relacionarlas visualmente para construir teorías narrativas.

## Propuesta de valor

ThreadBoard ofrece un espacio único donde una persona puede reunir evidencias narrativas y observar relaciones que son difíciles de identificar cuando la información está dispersa.

## Usuario objetivo del MVP

- Usuario individual.
- Uso personal.
- No requiere cuenta.
- Interesado en analizar series, películas o videojuegos.

## Usuario futuro

En una segunda versión se contempla:

- cuentas de usuario;
- colaboración;
- comunidad;
- entidades más ricas para personajes y lugares;
- funciones de asistencia inteligente.

## Objetivo general

Desarrollar un MVP web que permita crear y explorar tableros narrativos visuales mediante nodos y conexiones persistentes.

## Objetivos específicos

1. Crear un modelo de dominio coherente para tableros, nodos, escenas, teorías y conexiones.
2. Desarrollar una API capaz de persistir y recuperar el grafo de un tablero.
3. Crear una interfaz visual con arrastre, zoom y paneo.
4. Permitir progresivamente la creación y edición de contenido real.
5. Validar la estabilidad mediante pruebas y verificaciones repetibles.
6. Mantener documentación técnica y de gestión durante todo el proyecto.

## Indicadores de éxito del MVP

- El usuario puede crear un tablero.
- Puede agregar escenas y teorías.
- Puede mover nodos y conservar sus posiciones.
- Puede conectar nodos y recuperar el grafo.
- Puede comprender la interfaz sin formación técnica.
- El sistema conserva integridad entre los datos relacionados.
