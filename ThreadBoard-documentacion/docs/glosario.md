# Glosario

| Término | Definición en ThreadBoard |
|---|---|
| Board | Tablero que agrupa nodos y conexiones de una investigación narrativa. |
| Node | Elemento posicionable del canvas. Puede representar una escena o una teoría. |
| Scene | Información narrativa asociada a un nodo de tipo escena. |
| Theory | Hipótesis o interpretación asociada a un nodo de tipo teoría. |
| Connection | Relación dirigida entre dos nodos del mismo tablero. |
| Graph | Representación agregada de nodos y conexiones de un tablero. |
| Graph View | Adaptación del grafo al formato esperado por React Flow. |
| Canvas | Superficie visual donde se muestran y manipulan los nodos. |
| React Flow | Biblioteca utilizada mediante `@xyflow/react` para el canvas de nodos y aristas. |
| DTO | Objeto que define y valida los datos aceptados por un endpoint. |
| ORM | Capa que conecta objetos de la aplicación con tablas de base de datos. |
| Prisma | ORM utilizado por el backend. |
| ADR | Registro breve de una decisión arquitectónica importante. |
| Sprint | Periodo de trabajo con un objetivo y entregables concretos. |
| MVP | Versión mínima que permite validar la propuesta central del producto. |
| Deuda técnica | Trabajo pendiente causado por una solución provisional, incompleta o que deberá mejorarse. |
